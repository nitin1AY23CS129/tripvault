# TripVault 🗺️

TripVault is a full-stack travel journal application that allows users to securely create, manage, and revisit their travel memories.

## 🚀 Features

- User registration
- Secure user login
- Password hashing with bcrypt
- JWT-based authentication
- Protected routes
- User profile information
- Create trips
- View saved trips
- View individual trip details
- Edit trips
- Delete trips
- Responsive and attractive travel-focused UI

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- React Router
- Axios
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- Multer
